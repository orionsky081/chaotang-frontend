## 第三次：修复 logo 全站不显示（开场/落地/登录/注册都空白）
- 根因：public/logo-dragon.svg 与 src/app/icon.svg 的 SVG mask 反转。原 mask 为「白色背景矩形(可视) + 黑色龙形 path(隐藏)」作用于金色矩形，结果是金色只在龙形之外显示，暗色页面下龙形区域透明/空 → 看似不展示（只有一层薄金边）。
- 修复：把 mask 改为「黑色背景(隐藏) + 白色龙形(可视)」，金色矩形仅在龙形区域显示 → 得到金色龙形剪影（透明底），暗色背景清晰可见。
- 提交 3843233 已 push 到 origin/main。
- 验证手段受限：本地无 rsvg/cairosvg（缺 libcairo），仅做了 XML 合法性校验 + mask 语义推导，未能出图渲染确认；建议用户拉取后硬刷新核对实际效果。
